## 🔖 วิธีใช้เอกสารนี้

1. **ดูตามหมวดหมู่** — เข้าโฟลเดอร์ที่สนใจเพื่อดูประวัติเฉพาะส่วน
2. **ดูตามลำดับเวลา** — แต่ละไฟล์เรียงตามเวลา เก่าสุดอยู่บน
3. **นำไปใช้กับระบบอื่น** — ใช้โครงสร้างนี้เป็นเทมเพลต ปรับเปลี่ยนหมวดหมู่ตามความเหมาะสม
4. **ดูแบบเจาะลึก** — ดูไฟล์ migration ต้นฉบับที่ `supabase/migrations/`
