## 1. การลงทะเบียนและเข้าสู่ระบบ

### 1.1 การลงทะเบียนครั้งแรก

หากเข้าใช้ระบบเป็นครั้งแรก ให้ทำตามขั้นตอนนี้:

1. เปิดเบราว์เซอร์ (Chrome / Edge แนะนำ)
2. ไปที่ **URL ของระบบ**
3. คลิกปุ่ม **"เข้าสู่ระบบด้วย Google"**
4. เลือกบัญชี Google ที่ต้องการใช้
5. กรอกข้อมูลส่วนตัว:
   - ชื่อ – นามสกุล
   - หมายเลขโทรศัพท์ (10 หลัก)
   - ภาควิชา / หน่วยงาน
   - ประเภทผู้ใช้ (นักศึกษา / อาจารย์ / เจ้าหน้าที่)
6. คลิก **"ลงทะเบียน"**
7. **รอการอนุมัติจาก Admin** — ระบบจะแจ้งเตือนเมื่อบัญชีพร้อมใช้งาน

> ℹ️ ระหว่างรอการอนุมัติ จะเห็นหน้า "รอการยืนยัน" และยังเข้าใช้งานระบบไม่ได้

### 1.2 การเข้าสู่ระบบ (ผู้ที่ได้รับอนุมัติแล้ว)

1. ไปที่ URL ของระบบ
2. คลิก **"เข้าสู่ระบบด้วย Google"**
3. เลือกบัญชี Google
4. ระบบนำไปยังหน้าหลักโดยอัตโนมัติ

### 1.3 การออกจากระบบ

- คลิกที่รูปโปรไฟล์มุมขวาบน
- คลิก **"ออกจากระบบ"**

> 🔒 **ควรออกจากระบบทุกครั้ง** โดยเฉพาะเมื่อใช้คอมพิวเตอร์สาธารณะ

## 2. การค้นหาและดูอุปกรณ์

**เส้นทาง:** เมนูหลัก → **อุปกรณ์**

### 2.1 การดูรายการอุปกรณ์

อุปกรณ์ทั้งหมดแสดงในรูปแบบการ์ดพร้อมข้อมูล:
- ชื่ออุปกรณ์ และรูปภาพ
- หมวดหมู่ / ประเภท
- **สถานะปัจจุบัน**

### 2.2 สถานะของอุปกรณ์

| สถานะ | ความหมาย | สามารถยืมได้? |
|-------|---------|:---:|
| 🟢 **ว่าง** | พร้อมให้ยืม | ✅ ได้ |
| 🔵 **ถูกยืม** | มีผู้ยืมอยู่แล้ว | ❌ ไม่ได้ |
| 🟡 **ซ่อมบำรุง** | อยู่ระหว่างซ่อม | ❌ ไม่ได้ |
| ⚫ **เลิกใช้งาน** | ปลดระวางแล้ว | ❌ ไม่ได้ |

### 2.3 การค้นหาอุปกรณ์

1. พิมพ์ชื่ออุปกรณ์ในช่อง **"ค้นหา"**
2. ระบบแสดงผลแบบ Real-time ขณะพิมพ์
3. กรองเพิ่มเติมได้ด้วย:
   - **หมวดหมู่** — เลือกประเภทอุปกรณ์
   - **สถานะ** — แสดงเฉพาะอุปกรณ์ "ว่าง"

### 2.4 การดูรายละเอียดอุปกรณ์

คลิกที่การ์ดอุปกรณ์เพื่อดูข้อมูลเพิ่มเติม:
- รูปภาพ และ Serial Number
- คำอธิบายรายละเอียด (RAM, Storage, สเปค ฯลฯ)
- ตำแหน่งที่เก็บอุปกรณ์
- ประวัติการยืม (ถ้ามี)

## 3. การขอยืมอุปกรณ์

### ขั้นตอนการยืม:

**ขั้นที่ 1 — เลือกอุปกรณ์**
1. ไปที่หน้า **"อุปกรณ์"**
2. ค้นหาและเลือกอุปกรณ์ที่ต้องการ
3. ตรวจสอบว่าสถานะเป็น **"ว่าง"** (สีเขียว)

**ขั้นที่ 2 — กรอกแบบฟอร์มคำขอยืม**
1. คลิกปุ่ม **"ขอยืม"**
2. กรอกข้อมูล:

| ฟิลด์ | คำอธิบาย | หมายเหตุ |
|-------|----------|---------|
| วันที่ยืม | วันที่ต้องการรับอุปกรณ์ | บังคับกรอก |
| วันที่คืน | วันที่คาดว่าจะนำมาคืน | บังคับกรอก |
| เวลาคืน | เวลาที่จะนำมาคืน | บังคับกรอก |
| วัตถุประสงค์ | เหตุผลการยืม | บังคับกรอก |
| หมายเหตุ | ข้อมูลเพิ่มเติม (ถ้ามี) | ไม่บังคับ |

**ขั้นที่ 3 — ส่งคำขอ**
1. ตรวจสอบข้อมูลทั้งหมดให้ถูกต้อง
2. คลิก **"ส่งคำขอยืม"**
3. ระบบส่งการแจ้งเตือนไปยัง Staff/Admin โดยอัตโนมัติ
4. รอการแจ้งเตือนยืนยัน

> ℹ️ ระบบจะแจ้งเตือนทันทีเมื่อ Staff อนุมัติหรือปฏิเสธคำขอ

## 4. การจองอุปกรณ์ล่วงหน้า

การจองใช้สำหรับ **วางแผนล่วงหน้า** เมื่ออุปกรณ์ถูกยืมอยู่ หรือต้องการรับรองว่าจะได้ใช้ในช่วงเวลาที่ต้องการ

### ขั้นตอนการจอง:

1. ไปที่หน้า **"อุปกรณ์"**
2. เลือกอุปกรณ์ที่ต้องการจอง
3. คลิกปุ่ม **"จอง"**
4. เลือกวันและเวลา:
   - วันที่เริ่มต้นใช้งาน
   - วันที่สิ้นสุด / เวลาคืน
5. ระบุวัตถุประสงค์
6. คลิก **"ยืนยันการจอง"**
7. รอ Staff/Admin อนุมัติการจอง

### การดูสถานะการจอง:
- ไปที่เมนู **"การจองของฉัน"**
- ดูรายการการจองและสถานะ

> ℹ️ เมื่อการจองได้รับการอนุมัติ คุณจะได้รับการแจ้งเตือนในระบบ

## 5. การติดตามคำขอและสถานะ

### 5.1 คำขอยืมของฉัน

**เส้นทาง:** เมนูหลัก → **คำขอของฉัน**

ดูรายการคำขอยืมทั้งหมดพร้อมสถานะ:

| สถานะ | ความหมาย | สิ่งที่ต้องทำ |
|-------|---------|-------------|
| 🕐 **รอการอนุมัติ** | Staff กำลังพิจารณา | รอการแจ้งเตือน |
| ✅ **อนุมัติแล้ว** | ได้รับอนุญาตให้ยืม | ไปรับอุปกรณ์ |
| 📦 **กำลังยืม** | ยืมอยู่ในปัจจุบัน | คืนตามกำหนด |
| ✔️ **คืนแล้ว** | ธุรกรรมเสร็จสิ้น | — |
| ❌ **ปฏิเสธ** | คำขอไม่ได้รับอนุมัติ | ดูเหตุผล / ขอยืมใหม่ |

### 5.2 การยกเลิกคำขอ

สามารถยกเลิกคำขอได้เฉพาะเมื่อสถานะเป็น **"รอการอนุมัติ"**:
1. ไปที่ **"คำขอของฉัน"**
2. คลิกคำขอที่ต้องการยกเลิก
3. คลิก **"ยกเลิกคำขอ"** → ยืนยัน

## 6. การคืนอุปกรณ์

เมื่อต้องการนำอุปกรณ์มาคืน:

1. นำอุปกรณ์ (พร้อมอุปกรณ์เสริมทั้งหมด) ไปที่ **เคาน์เตอร์เจ้าหน้าที่**
2. แจ้งชื่อและอุปกรณ์ที่ต้องการคืน
3. **เจ้าหน้าที่จะบันทึกการคืนในระบบ**
4. รอรับการยืนยันจากเจ้าหน้าที่ว่าบันทึกสำเร็จ
5. สถานะคำขอจะเปลี่ยนเป็น **"คืนแล้ว"** ในระบบ

> ⚠️ **สิ่งที่ควรทำก่อนคืน:**
> - ตรวจสอบสภาพอุปกรณ์และรายงานความเสียหาย (ถ้ามี) ให้เจ้าหน้าที่ทราบ
> - ลบข้อมูลส่วนตัวออกจากอุปกรณ์ก่อนคืน
> - คืนอุปกรณ์เสริมให้ครบ (สายชาร์จ, กระเป๋า ฯลฯ)

---

## 7. การแจ้งเตือน

**เส้นทาง:** ไอคอนระฆัง 🔔 มุมขวาบน

### ประเภทการแจ้งเตือนที่จะได้รับ:

| ประเภท | เมื่อไหร่ |
|--------|---------|
| บัญชีได้รับการอนุมัติ | เมื่อ Admin อนุมัติบัญชีใหม่ |
| คำขอได้รับอนุมัติ | เมื่อ Staff อนุมัติคำขอยืม |
| คำขอถูกปฏิเสธ | เมื่อ Staff ปฏิเสธคำขอ (พร้อมเหตุผล) |
| แจ้งเตือนใกล้วันคืน | ก่อนถึงวันที่กำหนดคืน |
| ข้อความจาก Admin | เมื่อ Admin ส่งข้อความผ่าน Support Chat |

### การดูการแจ้งเตือน:
1. คลิกไอคอนระฆัง 🔔 ที่มุมขวาบน
2. ดูรายการแจ้งเตือนทั้งหมด
3. คลิกการแจ้งเตือนเพื่อไปยังหน้าที่เกี่ยวข้อง

## 8. Support Chat (ติดต่อ Admin)

หากมีข้อสงสัยหรือต้องการความช่วยเหลือ สามารถติดต่อ Admin โดยตรงผ่านระบบ:

1. มองหาปุ่ม **💬 Support** ที่มุมล่างขวาของหน้าจอ
2. หากมีไอคอนสีแดง (badge) แสดงว่ามีข้อความใหม่จาก Admin
3. คลิกปุ่ม Support เพื่อเปิดหน้าต่างแชท
4. ดูข้อความและตอบกลับได้ทันที

> ℹ️ Admin เป็นผู้เริ่มการสนทนาเสมอ — ผู้ใช้ไม่สามารถเปิด Ticket ใหม่เองได้

## 9. โปรไฟล์ของฉัน

**เส้นทาง:** เมนูหลัก → **โปรไฟล์**

### ข้อมูลที่แก้ไขได้:
- ชื่อ – นามสกุล (ที่แสดงในระบบ)
- หมายเลขโทรศัพท์
- ภาควิชา / หน่วยงาน

### ข้อมูลที่ไม่สามารถแก้ไขเองได้:
- อีเมล (ผูกกับ Google Account)
- บทบาท (User / Staff / Admin) — ต้องติดต่อ Admin
- สถานะบัญชี

### ขั้นตอนแก้ไขโปรไฟล์:
1. ไปที่ **โปรไฟล์**
2. คลิก **"แก้ไขโปรไฟล์"**
3. ปรับข้อมูลที่ต้องการ
4. คลิก **"บันทึก"**

## 10. ข้อแนะนำการใช้งาน

### 📌 เพิ่มประสิทธิภาพการใช้งาน:
1. **วางแผนล่วงหน้า** — จองอุปกรณ์ก่อนวันที่ต้องการใช้
2. **ระบุเวลาคืนให้ชัดเจน** — ระบุเวลาคืนให้ตรงกับความเป็นจริง
3. **คืนตรงเวลา** — ช่วยให้ผู้อื่นได้ใช้อุปกรณ์ต่อ
4. **ตรวจสอบสถานะเป็นประจำ** — เข้าดูคำขอและการแจ้งเตือนสม่ำเสมอ

### ⚠️ สิ่งที่ควรระวัง:
1. **ห้ามให้ผู้อื่นใช้อุปกรณ์แทน** — อุปกรณ์ที่ยืมในชื่อของคุณ คุณต้องรับผิดชอบ
2. **ลบข้อมูลส่วนตัวก่อนคืน** — ล็อคเอาต์บัญชีทุกอย่างก่อนนำมาคืน
3. **รายงานความเสียหายทันที** — หากอุปกรณ์เกิดความเสียหาย ให้แจ้งเจ้าหน้าที่ทันที

## 11. การแก้ไขปัญหาเบื้องต้น

### ปัญหา: เข้าสู่ระบบไม่ได้
**วิธีแก้ไข:**
1. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
2. ตรวจสอบว่าบัญชีได้รับการอนุมัติแล้ว (ดูอีเมลการแจ้งเตือน)
3. ล้าง Cache และ Cookie ของเบราว์เซอร์
4. ลองเบราว์เซอร์อื่น

### ปัญหา: ส่งคำขอยืมไม่ได้
**วิธีแก้ไข:**
1. ตรวจสอบว่ากรอกข้อมูลทุกช่องที่จำเป็น
2. ตรวจสอบว่าวันที่คืนไม่ย้อนหลัง
3. ตรวจสอบว่าอุปกรณ์ยังมีสถานะ "ว่าง"
4. รีเฟรชหน้าเว็บแล้วลองใหม่

### ปัญหา: ไม่ได้รับการแจ้งเตือน
**วิธีแก้ไข:**
1. คลิกไอคอนระฆัง 🔔 เพื่อตรวจสอบการแจ้งเตือนในระบบโดยตรง
2. ตรวจสอบว่าเบราว์เซอร์อนุญาตการแจ้งเตือน
3. รีเฟรชหน้าเว็บ

### ปัญหา: ไม่พบอุปกรณ์ในการค้นหา
**วิธีแก้ไข:**
1. ตรวจสอบว่าพิมพ์ชื่ออุปกรณ์ถูกต้อง
2. ล้างตัวกรอง (filter) ทั้งหมดแล้วลองใหม่
3. รีเฟรชหน้าเว็บ

### ยังแก้ไขไม่ได้?
ติดต่อ Admin ผ่าน **Support Chat** (ปุ่ม 💬 มุมล่างขวา) หรือแจ้งเจ้าหน้าที่โดยตรง
