## 1. บทบาทและสิทธิ์ของ Admin

ผู้ดูแลระบบ (Admin) มีสิทธิ์สูงสุดในระบบ สามารถดำเนินการได้ทุกอย่าง ดังนี้:

| สิทธิ์ | รายละเอียด |
|--------|-----------|
| จัดการผู้ใช้ | เพิ่ม, แก้ไข, อนุมัติ, ระงับ, เปลี่ยนบทบาทผู้ใช้ |
| จัดการอุปกรณ์ | เพิ่ม, แก้ไข, ลบ, เปลี่ยนสถานะอุปกรณ์ |
| จัดการการยืม-คืน | อนุมัติ/ปฏิเสธคำขอ, ติดตามการยืมค้าง |
| ดูรายงานสถิติ | ดูกราฟ, Export CSV, ดูข้อมูลเชิงลึก |
| Support Chat | ส่งข้อความหาผู้ใช้โดยตรง |
| ตั้งค่าระบบ | แก้ไข Discord Webhook, จำนวนยืมสูงสุด |
| ดูบันทึกกิจกรรม | ตรวจสอบกิจกรรมทั้งหมดของ Staff |

## 2. การเข้าสู่ระบบ

### ขั้นตอน:
1. เปิดเบราว์เซอร์ (Chrome / Edge แนะนำ) ไปที่ URL ของระบบ
2. คลิกปุ่ม **"เข้าสู่ระบบด้วย Google"**
3. เลือกบัญชี Google ที่มีสิทธิ์ Admin
4. ระบบจะนำไปยัง **หน้า Admin Dashboard** โดยอัตโนมัติ

> ⚠️ หากเข้าสู่ระบบแล้วไม่เห็นเมนู Admin ให้ตรวจสอบว่าบัญชีได้รับการกำหนดบทบาท `admin` ในฐานข้อมูลแล้ว

## 3. หน้า Dashboard (ภาพรวมระบบ)

หน้าแรกหลังเข้าสู่ระบบจะแสดง **ข้อมูลสรุปทั้งหมด** ในรูปแบบการ์ดและกราฟ:

### ข้อมูลที่แสดง:
- **จำนวนอุปกรณ์ทั้งหมด** — แยกตามสถานะ (ว่าง / ถูกยืม / ซ่อมบำรุง)
- **คำขอยืมรออนุมัติ** — จำนวนคำขอที่ยังไม่ดำเนินการ
- **อุปกรณ์ค้างคืน** — รายการที่เลยกำหนดคืน
- **ผู้ใช้งานในระบบ** — จำนวนผู้ใช้ทั้งหมดแยกตามบทบาท
- **กราฟการยืม** — สถิติรายเดือน

### การนำทาง:
- คลิกการ์ดสรุปเพื่อไปยังส่วนที่เกี่ยวข้องโดยตรง
- ใช้เมนูด้านซ้าย (Sidebar) เพื่อไปยังส่วนต่าง ๆ

## 4. การจัดการผู้ใช้

**เส้นทาง:** Admin → จัดการผู้ใช้ (Users)

### 4.1 การอนุมัติผู้ใช้ใหม่

เมื่อผู้ใช้ลงทะเบียนเข้าสู่ระบบครั้งแรก จะรอการอนุมัติจาก Admin:

1. ไปที่ **Admin → จัดการผู้ใช้**
2. ดูแท็บ **"รอการอนุมัติ"** หรือกรองสถานะ `pending`
3. คลิกดูรายละเอียดผู้ใช้ที่ต้องการ
4. ตรวจสอบข้อมูล: ชื่อ, อีเมล, ภาควิชา, ประเภทผู้ใช้
5. คลิก **"อนุมัติ"** หรือ **"ปฏิเสธ"**
6. ระบบจะส่งการแจ้งเตือนให้ผู้ใช้ทันที

### 4.2 การแก้ไขข้อมูลและสิทธิ์ผู้ใช้

1. ค้นหาผู้ใช้จากชื่อหรืออีเมล
2. คลิกปุ่ม **"แก้ไข"**
3. ปรับแก้ข้อมูล:
   - **บทบาท (Role):** `user` / `staff` / `admin`
   - **สถานะ (Status):** อนุมัติ / ระงับ
   - ชื่อ, เบอร์โทร, ภาควิชา
4. คลิก **"บันทึก"**

### 4.3 การระงับผู้ใช้

1. ค้นหาและเปิดโปรไฟล์ผู้ใช้
2. เปลี่ยนสถานะเป็น **"ระงับ"**
3. บันทึก — ผู้ใช้จะไม่สามารถเข้าระบบได้ทันที (ข้อมูลยังคงอยู่)

> ℹ️ การลบผู้ใช้จะลบข้อมูลออกจากระบบถาวร ควรใช้การ "ระงับ" แทนในกรณีทั่วไป

## 5. การจัดการอุปกรณ์

**เส้นทาง:** Admin → จัดการอุปกรณ์ (Equipment)

### 5.1 การเพิ่มอุปกรณ์ใหม่

1. คลิกปุ่ม **"+ เพิ่มอุปกรณ์"**
2. กรอกข้อมูล:

| ฟิลด์ | คำอธิบาย | ตัวอย่าง |
|-------|----------|---------|
| ชื่ออุปกรณ์ | ชื่อที่แสดงในระบบ | MacBook Air M2 |
| ประเภท/หมวดหมู่ | เลือกจากรายการ | โน้ตบุ๊ค |
| Serial Number | หมายเลขเครื่อง (ถ้ามี) | C02XK0JJJGH6 |
| รุ่น/ยี่ห้อ | ข้อมูลรุ่น | Apple MacBook Air 13" |
| คำอธิบาย | รายละเอียดเพิ่มเติม | RAM 8GB, SSD 256GB |
| ตำแหน่งเก็บ | สถานที่เก็บอุปกรณ์ | ห้องเก็บอุปกรณ์ ชั้น 2 |
| สถานะเริ่มต้น | สถานะแรกของอุปกรณ์ | ว่าง (ready) |

3. อัปโหลดรูปภาพอุปกรณ์ (แนะนำ)
4. คลิก **"บันทึก"**

### 5.2 การแก้ไขข้อมูลอุปกรณ์

1. ค้นหาอุปกรณ์ หรือกรองตามประเภท/สถานะ
2. คลิกปุ่ม **"แก้ไข"** ที่การ์ดอุปกรณ์
3. แก้ไขข้อมูลที่ต้องการ
4. คลิก **"บันทึก"**

### 5.3 การเปลี่ยนสถานะอุปกรณ์

| สถานะ | ความหมาย |
|-------|---------|
| 🟢 **ว่าง (ready)** | พร้อมให้ยืม |
| 🔵 **ถูกยืม (borrowed)** | มีผู้ยืมอยู่ |
| 🟡 **ซ่อมบำรุง (maintenance)** | อยู่ระหว่างซ่อม |
| ⚫ **เลิกใช้งาน (retired)** | ปลดระวางแล้ว |

**ขั้นตอนเปลี่ยนสถานะ:**
1. เปิดรายการอุปกรณ์
2. คลิกเมนู **"⋮"** หรือปุ่ม **"เปลี่ยนสถานะ"**
3. เลือกสถานะใหม่
4. ระบุเหตุผล (ถ้ามี)
5. คลิก **"ยืนยัน"**

### 5.4 การลบอุปกรณ์

> ⚠️ **ควรเปลี่ยนสถานะเป็น "เลิกใช้งาน" ก่อนลบเสมอ** และต้องตรวจสอบว่าไม่มีการยืมค้างอยู่

1. เปลี่ยนสถานะอุปกรณ์เป็น **"เลิกใช้งาน"**
2. คลิก **"ลบ"**
3. ยืนยันการลบ

## 6. การจัดการประเภทอุปกรณ์

**เส้นทาง:** Admin → ประเภทอุปกรณ์ (Equipment Types)

ใช้สำหรับจัดการหมวดหมู่และประเภทของอุปกรณ์ในระบบ

### ขั้นตอน:
1. ดูรายการประเภทอุปกรณ์ที่มีอยู่
2. **เพิ่มประเภทใหม่**: คลิก **"+ เพิ่มประเภท"** → กรอกชื่อ → บันทึก
3. **แก้ไขประเภท**: คลิก **"แก้ไข"** → ปรับชื่อ → บันทึก
4. **ลบประเภท**: ทำได้เฉพาะประเภทที่ไม่มีอุปกรณ์ผูกอยู่

## 7. การจัดการคำขอยืม

**เส้นทาง:** Admin → คำขอยืม (Loans)

### 7.1 การดูคำขอยืมทั้งหมด

ระบบแสดงคำขอแยกตามสถานะ:
- **รอการอนุมัติ** (pending)
- **อนุมัติแล้ว** (approved)  
- **กำลังยืม** (active)
- **คืนแล้ว** (returned)
- **ปฏิเสธ** (rejected)

### 7.2 การอนุมัติหรือปฏิเสธคำขอ

1. คลิกคำขอที่มีสถานะ **"รอการอนุมัติ"**
2. ตรวจสอบรายละเอียด:
   - ชื่อผู้ขอยืม / ภาควิชา
   - อุปกรณ์ที่ขอยืม
   - วันที่ยืม – วันที่คืน / เวลาคืน
   - วัตถุประสงค์
3. เลือกดำเนินการ:
   - **อนุมัติ** → คลิก **"อนุมัติ"** → ยืนยัน
   - **ปฏิเสธ** → คลิก **"ปฏิเสธ"** → ระบุเหตุผล → ยืนยัน
4. ระบบส่งการแจ้งเตือนให้ผู้ยืมอัตโนมัติ

> ℹ️ Staff และ Admin ที่ขอยืมเอง จะได้รับการ **อนุมัติอัตโนมัติ** โดยไม่ผ่านขั้นตอนนี้

### 7.3 การติดตามอุปกรณ์ค้างคืน

1. กรองสถานะ **"กำลังยืม"** และดูวันที่ครบกำหนด
2. อุปกรณ์ที่เลยกำหนดจะแสดงสีแดง / ป้าย "เกินกำหนด"
3. ดำเนินการได้:
   - ติดต่อผู้ยืมผ่าน Support Chat
   - บันทึกหมายเหตุ

## 8. การจัดการการจอง

**เส้นทาง:** Admin → การจอง (Reservations)

### ขั้นตอน:
1. ดูรายการการจองทั้งหมดพร้อมสถานะ
2. **อนุมัติการจอง**: คลิก **"อนุมัติ"** ที่การจองที่รออนุมัติ
3. **ปฏิเสธการจอง**: คลิก **"ปฏิเสธ"** พร้อมระบุเหตุผล
4. **ยกเลิกการจอง**: สำหรับการจองที่ไม่จำเป็น

> ℹ️ Staff และ Admin ที่ทำการจองเอง จะได้รับการ **อนุมัติอัตโนมัติ**

## 9. การยืมพิเศษ

**เส้นทาง:** Admin → การยืมพิเศษ (Special Loans)

ใช้สำหรับการยืมที่มีเงื่อนไขพิเศษนอกเหนือจากการยืมปกติ (เช่น ยืมข้ามคืน, ยืมออกนอกสถานที่)

### ขั้นตอน:
1. ดูรายการคำขอยืมพิเศษ
2. ตรวจสอบรายละเอียดและเหตุผล
3. อนุมัติหรือปฏิเสธพร้อมเหตุผล

---

## 10. การจัดการแบบประเมิน

**เส้นทาง:** Admin → แบบประเมิน (Evaluations)

หลังจากผู้ใช้คืนอุปกรณ์ ระบบจะรวบรวมแบบประเมินความพึงพอใจ

### ขั้นตอน:
1. ดูรายการแบบประเมินที่ได้รับ
2. วิเคราะห์คะแนนและความคิดเห็น
3. Export ข้อมูลเป็น CSV เพื่อนำไปวิเคราะห์เพิ่มเติม

---

## 11. รายงานและสถิติ

**เส้นทาง:** Admin → รายงาน (Reports)

### ข้อมูลที่ดูได้:
- **กราฟการยืมรายเดือน** — จำนวนการยืม-คืนแต่ละเดือน
- **อุปกรณ์ที่ได้รับความนิยม** — อันดับอุปกรณ์ที่ยืมมากที่สุด
- **ผู้ใช้งานที่ยืมบ่อย** — รายชื่อผู้ใช้แยกตามจำนวนครั้ง
- **สถิติการค้างคืน** — จำนวนครั้งที่เกินกำหนด
- **สรุปแบบประเมิน** — คะแนนความพึงพอใจ

### การกรองและ Export:
1. เลือกช่วงวันที่ที่ต้องการด้วย Date Picker
2. ดูข้อมูลในกราฟแบบ Real-time
3. คลิก **"Export CSV"** เพื่อดาวน์โหลดข้อมูลเป็นไฟล์ Excel/CSV

## 12. Support Chat (ระบบแชทกับผู้ใช้)

**เส้นทาง:** Admin → Support Chat

Admin สามารถเปิดการสนทนาและส่งข้อความถึงผู้ใช้งานโดยตรงผ่านระบบ

### ขั้นตอนเปิด Ticket ใหม่:
1. ไปที่ **Admin → Support Chat**
2. คลิก **"สร้าง Ticket ใหม่"**
3. เลือกผู้ใช้ที่ต้องการติดต่อ
4. พิมพ์ข้อความ → คลิก **"ส่ง"**
5. ผู้ใช้จะเห็นไอคอนแจ้งเตือน (badge) ที่ปุ่ม Support ในหน้าหลัก

### การตอบกลับ Ticket:
1. คลิกที่ Ticket ในรายการ
2. ดูประวัติการสนทนา
3. พิมพ์ข้อความตอบกลับ → คลิก **"ส่ง"**

---

## 13. บันทึกกิจกรรมเจ้าหน้าที่

**เส้นทาง:** Admin → บันทึกกิจกรรม (Staff Activity)

ระบบบันทึกกิจกรรมสำคัญของ Staff ทุกคนเพื่อการตรวจสอบย้อนหลัง (Audit Trail)

### ข้อมูลที่บันทึก:
- ชื่อ Staff ที่ดำเนินการ
- ประเภทกิจกรรม (อนุมัติ / ปฏิเสธ / คืนอุปกรณ์ / ฯลฯ)
- วันที่และเวลา
- รายละเอียดที่เกี่ยวข้อง

### การค้นหาบันทึก:
1. กรองตามช่วงวันที่
2. กรองตามชื่อ Staff
3. กรองตามประเภทกิจกรรม

---

## 14. การตั้งค่าระบบ

**เส้นทาง:** Admin → การตั้งค่า (Settings)

### 14.1 ตั้งค่า Discord Webhook

ใช้สำหรับรับการแจ้งเตือนอัตโนมัติจากระบบ:

1. ไปที่แท็บ **"การแจ้งเตือน Discord"**
2. กรอก URL Webhook สำหรับแต่ละช่อง:
   - **General** — แจ้งเตือนทั่วไป
   - **Auth** — แจ้งเตือนการลงทะเบียน/เข้าสู่ระบบ
   - **Reservation** — แจ้งเตือนการจอง
3. คลิก **"บันทึก"**

### 14.2 ตั้งค่าจำนวนยืมสูงสุด

1. ไปที่แท็บ **"ขีดจำกัดการยืม"**
2. ตั้งค่าจำนวนอุปกรณ์สูงสุดที่แต่ละบทบาทสามารถยืมได้พร้อมกัน:
   - จำนวนสูงสุดสำหรับ **User**
   - จำนวนสูงสุดสำหรับ **Staff**
3. คลิก **"บันทึก"**

> 🔒 ค่า Webhook URL ปลอดภัย — เข้าถึงได้เฉพาะ Admin เท่านั้น
